# 公开代码与商业流程交付边界

本开发分支的公开内容包括平台运行时、界面、包规范、制作 Skill、标准库示例、工具和测试。示例使用合成数据与临时本地模拟服务。

通用自动化 SDK 也纳入开源范围：已实现的 `awm.sdk` 以及规划中的浏览器会话、交互操作和步骤组件。浏览器及双模式输入目前属于 M2.1 设计，尚未交付；具体网站定位器、业务步骤和客户配置保留在独立流程包。

根目录现有 MIT 许可证保持不变。本文件只记录项目组织方式，不为既有文件重新授权，也不代表所有业务场景因此获得合规保证。

完全离线、内网部署与数据本地留存是核心产品定位。平台运行不依赖云账号、在线激活或云模型；未来商业交付如需授权机制，应支持离线使用。涉密环境部署要求与当前验证状态见 [离线部署要求](OFFLINE_DESIGN.md)，不将开源或断网运行等同于取得认证。

`original_process` 远程分支和 `process` 标签仍引用历史业务脚本。这些引用没有在本次工作中删除或改写，也不会被打入两个公开示例。发布前的处置方案：先确认历史保留需求及相应权利，必要时备份到适当的独立存储，再单独执行已明确授权的远程引用和历史处理。仅从当前工作树移除内容不能消除历史访问。

新的客户流程、客户数据、访问凭据和专有适配代码使用独立私有仓库或客户交付目录。合同中明确需求、验收、交付形式、适用授权和维护范围。具体商业交付条款安排在 M4 客户试点。

平台与公开包作者对版本、参数、能力和运行行为作明确声明。客户的具体流程实现和授权应在相应交付中处理，不将历史业务脚本移植为默认流程。
