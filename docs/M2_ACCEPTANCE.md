## 实际修复的问题

- 旧启动方式依赖独立 Vite 服务，且关闭窗口后后台线程无法自然结束；现已改为受管理的同源服务。
- Axios 的依赖目录和注册时机有问题；现使用浏览器原生 fetch 与显式会话初始化。
- 旧脚手架依赖审计存在问题；更新兼容版本并锁定依赖。最新 TypeScript 与当前 vue-tsc 组合在构建时发生导出路径错误，回到实际通过验证的 TypeScript 5.9.3。
- 子进程继承 stdout 可能阻止收集器结束；加入进程树归属和回归测试。
- 导入失败的提示原本会被弹窗遮挡；弹窗内也显示错误。
- 保存普通偏好不应强制提供本次运行凭据；已允许不填秘密保存配置，启动时仍校验必填秘密。
