# AutoMaticWorker frontend

Vue 3 + TypeScript. From this directory run `npm ci` and `npm run build`.
The Python desktop host serves `dist` on the same loopback origin as `/api`.
For hot-reload development, start `main.py --browser --port 5000` from the repository root, then run `npm run dev` here.
See [quick start](../docs/QUICKSTART.md) and [M2 acceptance](../docs/M2_ACCEPTANCE.md).
